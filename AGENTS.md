# Townlight Courts Agent Notes

Do not implement court case management, e-filing, warrant issuance, judicial decisions, legal advice, sealed-record exposure, juvenile-record exposure, live LLM calls, or court CMS connectors in v0.1.1.

Use `civiccore==0.3.0` and do not import from Townlight Core placeholder packages.
