CivicCourt User Manual

For staff: use CivicCourt to draft cited court procedure answers, prepare court form drafts, search public sample records while hiding restricted records, build hearing preparation checklists, and optionally retrieve saved form and hearing-prep workpapers when IT enables persistence and retrieval auth. Court clerks approve every output before use. Published version 0.1.2 is a foundation label under suite-wide release-recovery review. Do not promote it as production court software until the recovery gates and a future v1.0.0 definition of done are complete.

Boundaries: CivicCourt does not decide cases, issue warrants, file documents, provide legal advice, expose sealed or juvenile records, or replace court case-management systems.

For IT: install with python -m pip install -e ".[dev]" and run with python -m uvicorn civiccourt.main:app --host 127.0.0.1 --port 8143. Depends on the published CivicCore v0.4.0 release wheel. Set CIVICCOURT_WORKPAPER_DB_URL to enable SQLAlchemy-backed court form and hearing-prep workpaper records. Set CIVICCOURT_AUTH_TOKEN_ROLES to a JSON token-to-role map before exposing GET retrieval endpoints. Without the database variable, POST endpoints remain deterministic and stateless and GET retrieval endpoints return actionable persistence guidance. Without the auth variable, GET retrieval endpoints return actionable auth guidance.
